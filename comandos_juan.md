# 🧠 Comandos Disponibles para Juan

Esta es la guía de referencia rápida para interactuar con Juan. Recuerda que para ejecutar comandos de voz debes iniciar tu frase con la palabra de activación ("Wake Word").

## 🎙️ Palabra de Activación (Wake Word)
Juan te escucha continuamente, pero solo actúa cuando dices esta palabra primero:
- `juan`

*Ejemplo de uso:* `"Juan, abre la calculadora"` o `"Juan, qué hora es"`.

---

## ⚡ Comandos del Sistema y Ventanas

| Comando de voz (Ejemplos) | Acción |
| :--- | :--- |
| `"Abre [aplicación]"` | Abre la aplicación mencionada (Ej. *abre notepad*, *abre explorador*, *abre word*). |
| `"Cierra [aplicación]"` | Cierra la aplicación de manera forzada. |
| `"Minimiza [aplicación]"` | Minimiza la ventana de la aplicación. |
| `"Maximiza [aplicación]"` | Restaura o maximiza la ventana. |
| `"Sube el volumen"`, `"Más volumen"` | Sube el volumen del PC. |
| `"Baja el volumen"`, `"Menos volumen"` | Baja el volumen del PC. |
| `"Silencia"`, `"Mute"`, `"Quitar volumen"` | Silencia por completo el sonido (Mute). |
| `"Bloquea la pantalla"`, `"Bloquea el equipo"` | Bloquea el inicio de sesión de Windows (Win+L). |
| `"Captura de pantalla"`, `"Toma foto a la pantalla"` | Guarda un *Screenshot* localmente. |

---

## 🌐 Navegación y Búsquedas

| Comando de voz (Ejemplos) | Acción |
| :--- | :--- |
| `"Busca en google [texto]"` | Abre el navegador de forma visible, navega a Google, escribe la búsqueda y presiona Enter automáticamente. |
| `"Busca en youtube [texto]"` | Abre YouTube y realiza la búsqueda especificada. |
| `"Abre la pagina de [sitio]"`, `"Abre youtube"` | Va directamente a `[sitio].com` sin buscar en Google. |

---

## 🎵 Control Multimedia

| Comando de voz (Ejemplos) | Acción |
| :--- | :--- |
| `"Reproduce"`, `"Pausa"`, `"Pon música"` | Alterna (Play/Pause) de la música que esté sonando de fondo en Windows. |
| `"Siguiente"`, `"Otra canción"` | Pasa a la siguiente pista. |
| `"Anterior"`, `"Regresa la canción"` | Regresa a la pista anterior. |

---

## ⏰ Tiempo y Asistencia

| Comando de voz (Ejemplos) | Acción |
| :--- | :--- |
| `"Qué hora es"`, `"La hora"` | Juan responderá hablando con la hora exacta actual. |
| `"Qué día es"`, `"La fecha"` | Juan responderá hablando con la fecha del día actual. |

---

## 🧠 Aprendizaje y Memoria

| Comando de voz (Ejemplos) | Acción |
| :--- | :--- |
| `"Aprende [alias] como [aplicacion]"` | Permite que enseñes sinónimos. Por ejemplo: `"Aprende navegador como chrome"`. La próxima vez que digas *"abre navegador"*, Juan sabrá que debe abrir chrome.exe. |
